# Atomos File Map

Copy this structure into the root of the Atomos repository:

```text
ATOMOS/
├── ATOMOS_CONSTITUTION.md
├── PROJECT_SPEC.md
├── ROADMAP.md
├── DECISIONS.md
├── README_START_HERE.md
│
├── .agents/
│   └── rules/
│       └── atomos.md
│
└── docs/
    └── debating/
        └── DEBATING_RULEBOOK.md
```

Antigravity's current workspace Rules location is `.agents/rules`. Google also documents `GEMINI.md` / `AGENTS.md` workspace context files, but the dedicated workspace Rules mechanism is the most direct place for this project's persistent coding constraints.
