1. EXECUTIVE OVERVIEW & MISSION
----------------------------------------------------------------------------------
Atomos is an enterprise-grade debate intelligence platform, forensic data archive,
and predictive analytics engine built specifically for the Sri Lankan World Schools
Debating Championship (WSDC) circuit.

For decades, competitive debating records across Sri Lankan schools were fragmented
across transient Tabbycat instances, paper scorecards, and local tournament archives.
Discrepancies in speaker naming, inconsistent institutional spelling, unstandardized
scoring metrics, and the lack of historical cross-tournament tracking made
circuit-wide longitudinal analysis impossible.

Atomos solves this fundamentally. It unifies, reconciles, and mathematically
standardizes multi-year tournament data into a single, sovereign relational SQLite
database (data/atomos.db). Operating on top of this foundation is a suite of
statistical engines that benchmark debater performance, evaluate adjudicator bias
and strictness, reconstruct elimination knockout brackets, simulate competitive
team clashes, and power an autonomous AI debate agent grounded in verified data.

Atomos serves three distinct user groups:
1. Debaters & Coaches: Deep tactical dossiers, head-to-head records, team
   performance trends, and longitudinal skill trajectories.
2. Tournament Adjudication Cores: Objective adjudicator intelligence dossiers,
   panel strictness calibration, and side balance analysis across motions.
3. Software Engineers & Web Developers: A headless, CORS-enabled REST API and
   precomputed static web datasets (data/web_export/) ready for instant
   integration with React, Next.js, Vue, or mobile applications.


2. THE COMPETITIVE DOMAIN CONTEXT (WSDC DEBATING IN SRI LANKA)
----------------------------------------------------------------------------------
To understand Atomos, one must understand the rules and nuances of the Sri Lankan
competitive debating circuit:

* Format: World Schools Debating Championship (WSDC) format.
* Matchup Structure: Two opposing teams - Proposition (Prop) and Opposition (Opp) -
  comprising 3 speakers per team.
* Speeches:
  - 3 Substantive Speeches per side (1st, 2nd, and 3rd speakers), each traditionally
    scored on a scale of 60.0 to 80.0 points (with 70.0 as expected circuit average).
  - 1 Reply Speech per side (given by either 1st or 2nd speaker), scored on a
    half-scale of 30.0 to 40.0 points (with 35.0 as average).
  - Team Total in a single debate: Sum of 3 substantives + 1 reply, ranging between
    210.0 and 280.0 points per judge ballot.
* Panels & Adjudication:
  - Debates may be judged by a single adjudicator or a multi-member panel (3, 5, or 7).
  - Panel decisions are awarded by majority vote (2-1, 3-0, 4-1, 5-0).
  - Total scores from each panelist must be averaged to derive the authoritative match
    score and speaker score.
* Speaker Tab Qualification Rule (The 3-Round Rule):
  - In official WSDC rules, a debater is only eligible for individual speaker awards
    if they spoke in at least 3 preliminary rounds. Debaters speaking in only 1 or 2
    rounds are ineligible for official speaker tab rankings. Atomos strictly enforces
    this distinction.
* Institutional Multi-Team Fielding:
  - Major debating schools field multiple squads (e.g., Royal College A, Royal B,
    D. S. Senanayake A, Ladies' College Gold, Bishop's College Purple).
  - In knockout rounds, teams from the same institution occasionally face each other
    or execute an institutional "closeout" (where the school decides which squad
    advances without debating).

4. DATA LAYER & RELATIONAL SCHEMA (atomos.db)
----------------------------------------------------------------------------------
The physical database resides at data/atomos.db. It enforces foreign key constraints
and covering indices across 10 core relational tables:

1.  tournaments: Metadata for each tournament (name, slug, year, season, dates).
2.  institutions: Canonical schools and universities (name, code, region, type).
3.  teams: Debating teams fielded by institutions (name, canonical name, tier).
4.  persons: Unique debater and adjudicator profiles (name, gender, national level).
5.  debater_aliases: Alias map linking misspellings and nicknames to canonical IDs.
6.  team_members: Mapping of persons to specific team rosters per tournament.
7.  rounds: Rounds within tournaments (number, stage name, type, motion, info slide).
8.  debates: Match records between Proposition and Opposition teams (venue, walkover).
9.  adjudicator_ballots: Individual scoresheets from each panelist (scores, margin).
10. speech_performances: Granular speech records (person ID, position, score).
11. precomputed_cache: High-speed materialized cache for precomputed analytics.

Active Database Scale:
* Tournaments: 9 major championships (Chaps 2026, SLSDC 2026, VVIDC 2026, Metho 2026,
  Vijis 2026, AISDC 2026, APIIT ISDC 2026, RIC 2026, IDC).
* Canonical Institutions: 69 registered schools.
* Registered Teams: 318 teams.
* Unique Persons Indexed: 772 debaters and judges.
* Contested Debates: 920 matches (including 12 documented walkovers).
* Ballots Audited: 928 adjudicator panel ballots.
* Speeches Evaluated: 6,442 individual substantive and reply speeches.


5. IDENTITY RECONCILIATION & ENTITY RESOLUTION
----------------------------------------------------------------------------------
In high school debating tournaments, student names are frequently registered with
discrepancies (misspellings, school prefixes, inverted names).

The Identity Merger Engine (src/atomos/normalizer/identity_merger.py) detects and
reconciles duplicates across 5 safe heuristic passes:
- EXACT_CASE: Identical names with differing capitalizations.
- SPACING_PUNCTUATION: Differences in whitespace, dots, or hyphens.
- NAME_INVERSION: FirstName LastName vs LastName FirstName.
- SUBSTRING_SAME_SCHOOL: Shortened names from the exact same institution.
- SAME_TEAM_COLLISION: Mathematical guard preventing merge if two people spoke in
  the exact same debate on the same team.

The Team ID Resolver (src/atomos/normalizer/team_resolver.py) enables manual and
automated grouping of multi-tournament team aliases.

National Team Status Registry:
Atomos tracks the Sri Lankan National Debating Contingent directly in debater
profiles and displays it across all leaderboards:
- 'Nat Trials': Debaters who competed in the National Selection Trials.
- 'Nat Pool, Trialed': Debaters who qualified for the National Pool via trials.
- 'Nat Pool, Direct': Debaters who received direct admission into the National Pool.


6. CORE ANALYTICAL & MODELING ENGINES
----------------------------------------------------------------------------------
Atomos implements 7 sophisticated analytical engines located in src/atomos/analytics/:

6.1 Master Tab Engine (master_tabs.py)
- Computes official speaker averages conforming to international WSDC tab rules.
- Enforces the 3-preliminary-round qualification threshold.
- Reconciles multiple adjudicator ballots into unweighted per-speech averages.
- Produces the National Master Speaker Tab and National Master Reply Tab.

6.2 Critical Statistics Engine (critical_stats.py)
- Measures Average Total Speaker Score (ATSS).
- Computes scoring consistency (standard deviation sigma across tournaments).
- Analyzes scoring ceiling (highest speech) and floor (lowest speech).
- Computes debate conversion rates (win % when debater spoke).
- Tracks outround break rates (% of tournaments advancing to knockouts).

6.3 Dynamic Elo Rating System (ratings.py)
- Zero-sum Elo rating system tailored to competitive debating (baseline: 1,500.0 pts).
- Dynamic K-factor adjusted by match importance (prelim vs elim) and score margin.
- Institutional Power Index (IPI): Combines squad Elo ratings, depth, and elim wins.
- Debater Performance Index (DPI): Debater impact derived from point deviations.

6.4 Adjudicator Intelligence Engine (judges.py)
- Side Bias Profile: Prop vs Opp win percentage, detecting statistically
  significant deviations from 50/50.
- Scoring Strictness Index: Benchmarks judge substantive score distribution against
  the national circuit benchmark (71.20 pts). Classifies adjudicators into:
  * Strict / Low-Scoring (>= 0.40 pts below circuit standard)
  * Circuit Standard / Moderate (within +/- 0.40 pts)
  * High-Scoring / Generous (>= 0.40 pts above circuit standard)
- Margin Tendencies: Frequency of close splits (<= 1.5 pts) vs blowouts (>= 4.0 pts).
- Outround Experience: Detailed record of elimination panels officiated.

6.5 Tournament Knockout Bracket Engine (brackets.py)
- Reconstructs elimination trees: Octofinals -> Quarters -> Semis -> Grand Final.
- Matchup nodes with lineups, speaker scores, panel votes, and margins.
- Identifies institutional closeouts where teams from the same school reach finals.

6.6 Predictive Clash Simulator (predictor.py)
- Simulates debates between any two teams using a 3-factor composite model:
  * 50% Squad Elo rating differential (logistic probability curve).
  * 35% Preliminary ATSS baseline scoring differential.
  * 15% National Contingent Density on active rosters.
- Outputs win probabilities, projected margins, competitiveness classifications,
  and key tactical factors.

6.7 Chronological Debater Trajectory (debater_profile.py)
- Reconstructs debater form over time in strict chronological tournament sequence.
- Tracks substantive averages, ceilings, floors, reply averages, and running career
  cumulative averages for longitudinal progress visualization.


7. HEADLESS REST API & PRECOMPUTED WEB INFRASTRUCTURE
----------------------------------------------------------------------------------
Atomos provides both a live REST API and precomputed static JSON exports.

Headless REST API (src/atomos/server.py):
- Built with Flask, featuring global CORS headers (Access-Control-Allow-Origin: *).
- Run server: python src/atomos/server.py --port 5000

Core API Endpoints:
- GET  /api/health                     : System status and database metrics
- POST /api/ask                        : Natural language query interface
- GET  /api/search?q=...               : Multi-entity search
- GET  /api/debaters/<id>/profile      : Full debater profile with trajectory
- GET  /api/leaderboard/speakers       : Multi-metric speaker tab with national filter
- GET  /api/tournaments/<slug>/bracket : Complete knockout bracket tree
- GET  /api/judges/<identifier>        : Adjudicator intelligence dossier
- GET  /api/judges?limit=...           : National judge leaderboard
- GET  /api/predict?team_a=...&team_b= : Match prediction with win probabilities
- GET  /api/national-pool              : All 27 national squad debaters
- GET  /api/debates/<debate_id>        : Granular scoresheet and ballots
- GET  /api/institutions               : Institutional Power Index leaderboard
- GET  /api/motions/summary            : Circuit-wide motion analytics

Static Web Exporter (scripts/export_web_data.py):
- Generates static JSON files into data/web_export/ for instant Jamstack page loads.
- Precomputed files: master_speaker_tab.json, master_reply_tab.json,
  critical_speaker_stats.json, institutional_power_index.json,
